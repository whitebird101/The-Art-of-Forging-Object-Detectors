# 造化重锤的秘密：计算图、梯度与反向传播（四）



## 2.4 终极显影 ── 多尺度输出与检测头

FPN构建了三个不同尺度的融合特征图。

> P3: [B, 32, 32, 32]
> 
> P4: [B, 64, 16, 16]
> 
> P5: [B,128, 8, 8]

现在还差最后一步，把这些特征图转化成真正的检测输出。也就是说，我们要为不同尺度构建对应的检测头，让每个尺度的特征图进入自己的输出分支，分别产生该尺度上的预测结果。

可以先粗暴理解为FPN 负责提炼特征，检测头负责把特征翻译成最终需要的预测。

最终的预测是什么样呢？事实上，模型并不是直接输出：这里有一架飞机，那里有一辆车，这个框就是目标位置。

神经网络的原始输出不会这么有“人味”。它真正输出的是一堆数字。这些数字通常表示一个位置像A类目标的得分，像B类目标的得分，像C类目标的得分（你的模型支持检测多少种类别，他就会输出多少个得分），以及，这个位置预测框的属性，比如顶点信息、旋转角度信息等。注意，是特征图上的每一个格子都会输出这些信息。也就是说，检测模型的原始输出更像一张密密麻麻的“候选预测表”。后续还需要经过解码、置信度筛选等等环节，才能变成我们正常看到的检测框结果。

这里，我们先不做完整后处理，只专注一件事，即如何把 FPN 的多尺度特征图，转换成模型的原始输出（即原始预测张量）。

<a id="section-001"></a>
### 2.4.1 原始预测张量的形状

假设现在是一个极简检测任务，模型支持的检测结果是2个类别，分别是：

> class 0：飞机
> 
> class 1：汽车

对于特征图上的每一个空间位置（每一个格子），模型都需要输出一条预测向量。这个向量包含了这个空间位置（格子）是飞机的得分，是汽车的得分以及检测框的若干属性。在这里，检测框的属性暂时设计成8个（表示检测框的4个顶点），那么这个向量的维度就是：

$$
num_{\mathrm{classes}} + 8 = 2 + 8 = 10
$$

也就是说，每个位置输出 10 个数字：

> [class0得分数, class1得分数, 框属性1, 框属性2, ..., 框属性8]

这里要注意，类别得分数不一定就是严格意义上的概率。网络分类头的原始输出通常是未经过最终解释的数值（称为logits）。经过sigmoid、softmax或后续解码之后，它们才更接近“概率”或“置信度”的含义。为了方便理解，我们先把它们叫作“类别得分”。

<a id="section-002"></a>
### 2.4.2 从一个位置到一张预测图

如果一个空间位置输出 10 个数字，那么一张 32×32 的特征图会输出多少条预测？答案是32 × 32 = 1024 条预测，每条预测有 10 个数字。

所以对 P3 这个尺度来说：

> P3: \[B, 32, 32, 32\]

经过检测头之后，我们希望得到：

> out3: \[B, 10, 32, 32\]

这里的含义是：

> B：一批图像
> 
> 10：每个位置输出 10 个预测值
> 
> 32×32：一共有 1024 个空间位置

同理：

> P4: \[B, 64, 16, 16\] → out4: \[B, 10, 16, 16\]
> 
> P5: \[B,128, 8, 8\] → out5: \[B, 10, 8, 8\]

三个尺度加起来，一共有：

32×32 + 16×16 + 8×8 = 1024 + 256 + 64 = 1344 个预测位置

也就是说，模型并不是只输出几个框。它先输出 1344 个候选位置上的预测向量，再由后续流程筛掉低质量结果。

这就是目标检测网络的基本套路：先密集预测，再筛选结果。

<a id="section-003"></a>
### 2.4.3 神识锁定：极简多尺度检测头

我们现在要做的，就是通过某个方法，将P3、P4、P5，转换为out3、out4、out5。

如果仔细观察一下P3、P4、P5和out3、out4、out5，就会发现，他们只是通道数不同，其他都一样，而调整通道，2.3.4节介绍过一个方法，就是1×1卷积。

在这里，我们先使用1×1卷积做一个极简版检测头。把特征图的通道数变成我们需要的输出维度：


```python
self.out_channels = num_classes + 8  # 2 + 8 = 10
self.head3 = nn.Conv2d(32, self.out_channels, kernel_size=1)
self.head4 = nn.Conv2d(64, self.out_channels, kernel_size=1)
self.head5 = nn.Conv2d(128, self.out_channels, kernel_size=1)
```

这里有三个检测头，分别接收三个尺度的特征图：

> head3 处理 P3，偏向小目标；
> 
> head4 处理 P4，偏向中目标；
> 
> head5 处理 P5，偏向大目标。

三个检测头的输出维度：

| **检测头** | **输入**          | **输出**          | **对应尺度**   |
|------------|-------------------|-------------------|----------------|
| head3      | \[B, 32, 32, 32\] | \[B, 10, 32, 32\] | P3 (stride=8)  |
| head4      | \[B, 64, 16, 16\] | \[B, 10, 16, 16\] | P4 (stride=16) |
| head5      | \[B, 128, 8, 8\]  | \[B, 10, 8, 8\]   | P5 (stride=32) |

最终，模型的 forward 方法返回一个包含三个张量的列表：


```python
def forward(self, x):
    # ... Backbone + FPN ...
    out3 = self.head3(P3)   # [B, 10, 32, 32]
    out4 = self.head4(P4)   # [B, 10, 16, 16]
    out5 = self.head5(P5)   # [B, 10,  8,  8]
    return [out3, out4, out5]
```

这里可能会有一个疑问：为什么先保留三个尺度的预测张量，而不是马上把它们合并起来？

因为三个尺度的空间大小不同（32×32、16×16、8×8），不能在 \[B, C, H, W\] 形态下直接拼成一个规整的大张量。但我们可以先把每个尺度整理成预测表，再进行拼接。

<a id="section-004"></a>
### 2.4.4 乾坤挪移：reshape / permute 维度转换

检测头输出的原始形状是：\[B, C, H, W\]

其中：C = 每个位置的预测维度，H × W = 预测位置数量

但模型得后续计算更喜欢\[B, H\*W, C\]这样的格式，它的含义更像一张表：第几张图，第几个预测位置，这个位置的预测向量。比如\[B, 1024, 10\]表示：每张图有 1024 个预测位置，每个位置有 10 个预测值。

要把\[B, C, H, W\]转换成\[B, H\*W, C\]这样的格式，需要使用pytorch库中提供的张量操作方法reshape和permute。虽然本章的代码中没有显式使用 reshape /permute，但这里先建立基本概念，因为它是理解后续章节的关键前置知识。

**1、**reshape**：重塑但不改变数据**

reshape就像把一副牌重新码放。牌还是那些牌，只是摆放方式变了。


```python
x = torch.randn(4, 10, 32, 32)
print(x.shape)  # torch.Size([4, 10, 32, 32])
B, C, H, W = x.shape
# 把后两维展平：32 × 32 = 1024
y = x.reshape(B, C, H * W)
print(y.shape)  # torch.Size([4, 10, 1024])
```

通过 reshape 操作，我们把张量 x 的后两维展平：

> \[4, 10, 32, 32\] → \[4, 10, 1024\]

所谓“展平”，就是指把原来由多个维度组织的数据，按顺序合并一个维度中。因为从多个维度合并为1个维度，因此形象的把这个操作称之为“展平”。具体到我们刚刚把张量 x 的后两维展平，就是把32 × 32两个空间维度合并成一个1024维的数据。

更具体的说。

32 × 32表示特征图上有32 × 32=1024个空间位置。

可以想象成：

> 第 0 行：
> 
> □ □ □ □ □ ... 32个
> 
> 第 1 行：
> 
> □ □ □ □ □ ... 32个
> 
> ...
> 
> 第31行：
> 
> □ □ □ □ □ ... 32个

总共1024 个位置，展平以后并不是这些位置消失了，而是把二维坐标(h, w)重新排成：

> 位置0
> 
> 位置1
> 
> 位置2
> 
> ...
> 
> 位置1023

所以，32×32 的二维位置网格展平后就变成了1024 个预测位置，这对目标检测特别重要，因为后面我们不一定关心它是“第几行第几列”，而更方便把它看成：这一尺度上一共有 1024 个预测位置。

**2、permute：调换维度顺序**

permute的作用是重新排列张量各个维度的位置。——内容不变，但维度的排列顺序变了。


```python
x = torch.randn(4, 10, 1024)
#B   C   H*W
y = x.permute(0, 2, 1)
#B   HW  C
print(y.shape)  # [4, 1024, 10]
```

permute方法的参数是原维度的编号,每个编号必须出现且只能出现一次。具体到刚刚的例子，permute(0, 2, 1)，就是在说：请按照0号、2号、1号的顺序重新排队。0号位不动，原来的2号位到1号位来，原来的1号位到2号位去。重新排队。

\[B, C, H\*W\] → \[B, H\*W, C\]，原来是通道维在前，现在是每个预测位置在前。

掌握了reshape /permute方法，我们可以对模型三个尺度的输出进行处理，得到更适合后续计算的张量形态。


```python
preds = []

for out in outputs:
    B, C, H, W = out.shape
    out = out.reshape(B, C, H * W)  # [B, C, H*W]
    out = out.permute(0, 2, 1)      # [B, H*W, C]
    preds.append(out)

preds = torch.cat(preds, dim=1)
print(preds.shape)
```

三个输出张量分别变成：

> out3: [B, 10, 32, 32] → [B, 1024, 10]
> 
> out4: [B, 10, 16, 16] → [B, 256, 10]
> 
> out5: [B, 10, 8, 8] → [B, 64, 10]

拼接后：

```python
= [B, 1344, 10]
```

这就是统一的多尺度预测表。也就是说，P3、P4、P5 三张不同尺度的预测图，最终整理成一张候选预测表。后续真正的 YOLO / OBB 检测头，会在这个基础上继续进行“分类得分处理”、“边界框解码”、“置信度筛选”等一系列操作，最终得到我们期待的检测结果：类别、置信度、位置、宽高、角度等。
